# Portfolio Assignment 1

Vanilla HTML5, CSS3 and JavaScript portfolio for the Web Technology Assignment 1.

## Required structure
- index.html
- css/style.css
- js/script.js
- images/
- assets/ (resume placeholder)

## Before submission
1. Replace placeholder email, phone, GitHub and LinkedIn links.
2. Replace the resume placeholder with your actual resume.
3. Replace GitHub repository links in `js/script.js` with your actual project repositories.
4. Rename the GitHub repository to `YOUR_ROLLNO_YOURNAME_Portfolio`.
5. Test the site in a browser.
6. Enable GitHub Pages.
